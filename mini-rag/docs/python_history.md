# A Short History of Python

Python was created by Guido van Rossum and first released in February 1991. Van Rossum began work on it in December 1989 as a hobby project over the Christmas holidays, aiming to build a successor to the ABC language.

The name comes from the British comedy series Monty Python's Flying Circus, not the snake.

Python 2.0 was released in October 2000 and introduced list comprehensions and a garbage collector capable of collecting reference cycles. Python 3.0, released in December 2008, was a major backwards-incompatible revision that cleaned up long-standing design issues; the most visible change was making print a function.

Python 2 reached end of life on January 1, 2020.

Van Rossum held the title "Benevolent Dictator For Life" (BDFL) until he stepped down in July 2018. Python is now governed by a five-person Steering Council elected annually by core developers.

The language is managed by the Python Software Foundation, a non-profit founded in 2001.
